# 视频播放器复刻约定

## 参照版本

KikoFlu 的视频播放器以 [PiliPlus 2.1.6.2](https://github.com/bggRGjQaUbCoE/PiliPlus/releases/tag/2.1.6.2) 为复刻基准。
源码固定为提交 [`b2d6a5befb6dd292b9f7ad98794f3620f6dfb818`](https://github.com/bggRGjQaUbCoE/PiliPlus/tree/b2d6a5befb6dd292b9f7ad98794f3620f6dfb818)。
后续源码对照与验收使用该提交。

## 覆盖平台

复刻覆盖 Android、iOS、Windows、macOS 和 Linux。
各平台分别验收。
各平台以参照版本对应平台的界面与行为为准。

## 功能范围

复刻包含 KikoFlu 已有和缺少的通用视频播放能力。
播放操作与选项遵循 PiliPlus 参照版本，以下保留规则除外。

清晰度、字幕和音轨等功能适配现有视频源。
缺少源数据的功能入口不显示。
本次不新增 B 站视频源、账号或接口接入。

### 保留规则

- 音声与视频允许同时播放，应用内音量分别调整。
- 返回前台时，已暂停的视频需要手动继续播放。
- 音轨选择等 KikoFlu 独有能力继续保留。
  入口复用 KikoFlu 的共用 Material 菜单，名称按实际能力填写。
- 选项菜单跟随页面明暗主题，竖屏从底部弹出，横屏从右侧弹出。
  贴在按钮旁的小菜单保留锚点。
- 音频与视频播放器的更多面板共用“更多”标题和顶部间距。
  标题固定在面板顶部，选项内容单独滚动。

## 界面范围

复刻包含以下范围：

- 内嵌与全屏的视频画面。
- 播放控件与播放手势。
- 播放器弹出菜单。
- 视频播放设置。

竖屏时，视频详情页保留现有结构。
内嵌播放器占满视频详情页的可用宽度。
横屏时，内嵌播放器位于视频详情页左侧。
视频详情页的其余现有内容全部放在右侧，保留内容和功能。
分栏沿用作品详情页规则：左侧占 40%，右侧占 60%。
左侧播放器固定，右侧信息独立滚动。
视频信息和“相关推荐”保留原有边距。

上下控制栏的背景铺满播放器范围。
视频控制层使用播放器的完整宽度，不随视频画面缩窄。
标题栏、进度条和播放控件延伸到视频左右黑边。
视频画面保持当前选择的画面比例。
所有平台共用这条布局规则。
内嵌使用页面分配的范围，全屏使用可用窗口。
仅控件避让刘海、挖孔和系统导航区域。

Android 仅在视频全屏时隐藏顶部系统状态栏。
暂停时保持隐藏，退出全屏后恢复显示。
底部系统导航栏沿用现有显示规则。

## 播放行为

视频框包含播放画面和播放控件。

| 行为 | 复刻后的规则 |
| --- | --- |
| 双击画面 | 按 PiliPlus 参照版本启用快退与快进，默认跳转 10 秒；可选 5、10、15 秒 |
| 长按加速 | 按 PiliPlus 参照版本临时加速，默认切换到 3 倍速 |
| 倍速列表 | 默认 0.5、0.75、1、1.25、1.5、1.75、2、3 倍速；支持增删与设置默认倍速 |
| 临时倍速 | 播放器内切换倍速只影响当前视频；新视频使用设置中的默认倍速 |
| 临时画面设置 | 翻转和超分辨率只影响当前视频；新视频恢复关闭 |
| 控件显隐 | 动画时长 100 毫秒；默认 3 秒后隐藏，可延长到 30 秒 |
| 进度条 | 显示播放与缓冲进度，左右各留 20 像素。轨道高 3.5 像素，滑块半径 7 像素，光晕半径 25 像素 |
| 更多菜单 | 顶栏打开共用选项菜单；内嵌竖屏时从窗口底部弹出，顶部位于视频框下方；下方空间不足以显示标题和操作项时使用窗口可用高度；横屏从窗口右侧弹出，全屏沿用屏幕可用高度；底栏保留直接操作入口 |
| 顶栏 | 左侧显示返回与主页，右侧显示可用操作。按钮宽 42、高 34 像素，上下各留 12 像素，不加横向外边距 |
| 底栏 | 控件左右各留 10 像素，上下各留 12 像素。进度条独占一排，下排左侧显示播放和时间，右侧显示可用选项 |
| 音量调整 | 调整视频的应用内音量，不改系统音量或音声的应用内音量 |
| 从后台返回 | 已暂停的视频保持暂停，手动继续播放 |
| 音轨选择 | 合并为一个入口并显示当前音轨；点击后在更多面板内展开，选中后收起列表并保留面板 |

### 全屏切换

全屏采用 PiliPlus 参照版本的同页切换方式。
内嵌与全屏由视频详情页调整布局，使用同一播放会话和视频画面控件。
全屏时，播放器占满可用窗口，页头、播放条和右侧信息隐藏。
退出后恢复对应方向的详情页布局，并保留信息的滚动位置。
全屏切换保留当前播放状态和进度。
保持横屏退出时，播放器从全屏连续缩回详情页中的位置。
右侧信息栏同步显示，滚动位置保持不变。
音声播放条的高度按同一动画进度恢复，避免裁切收回中的视频画面。
系统禁用动画时直接恢复详情页布局。

返回操作先沿用播放器的解锁规则，再退出全屏，最后离开视频详情页。
桌面的系统全屏与应用内全屏保留各自入口。
同页承载的原因见 [ADR 0007](../adr/0007-inline-video-fullscreen.md)。

### 全屏退出

移动端退出全屏时，恢复系统的屏幕方向规则。
开启系统自动旋转时，返回退出时手机方向对应的页面布局。
关闭系统自动旋转时，返回系统锁定方向对应的页面布局。

退出全屏时直接显示视频详情页。
方向恢复期间不单独显示竖屏全屏播放器。
退出流程仍等待原生窗口布局回执与 Flutter 窗口方向一致。
Android 手机锁定方向时，实际窗口必须符合系统锁定方向后才完成回执。
开启自动旋转时，全屏期间采样手机方向。
实际窗口匹配持握方向后，完成回执。
手机平放且无法判断方向时，保留最近一次方向或进入全屏前的方向。
大屏、多窗口和外接显示器沿用实际窗口布局回执。
系统未响应方向请求时，等待最多 2 秒后按实际窗口结束退出。
释放播放器时结束尺寸等待。
手动退出和自动退出共用这条规则。
全屏切换保留当前播放状态和进度。

### 桌面快捷键

| 快捷键 | 行为 |
| --- | --- |
| 空格 | 播放或暂停 |
| 左方向键 | 按快进快退设置跳转，默认快退 10 秒 |
| 右方向键 | 松开时快进；按住 200 毫秒后临时加速，松开恢复 |
| 上、下方向键 | 视频音量增加、减少 10 个百分点 |
| F | 切换系统全屏 |
| Shift+F | 切换应用内全屏 |
| Shift+1、Shift+2 | 当前视频切换到 1、2 倍速 |
| P | 非全屏时切换桌面画中画 |
| S | 全屏时截图 |
| L | 全屏或桌面画中画时切换锁定 |
| Esc | 解锁或退出全屏 |

### 后台播放与画中画

后台播放默认关闭。
普通退后台或锁屏时，视频暂停并保存续播进度。
用户明确开启后台播放，或视频正在画中画中播放时，视频继续播放。
已暂停的视频返回前台后不自动恢复播放。

## 新增播放能力

按参照版本补齐通用播放能力，包括：

- 亮度和音量手势。
- 全屏锁定和截图。
- 缩放、画面比例和裁切。
- 双指缩放与移动画面，点击“还原屏幕”恢复。
- 循环模式和键盘快捷键。
- 字幕显示与设置。
- 后台播放和画中画。
- 左右与上下翻转、加载本地 VTT、SRT、ASS 字幕。
- 重载当前视频和查看播放信息。
- 定时关闭，支持暂停视频、退出应用和播完当前视频后执行。
- 超分辨率，使用参照版本的 Anime4K“效率”和“画质”预设。
- 全屏时钟与电量显示；移动端电量显示默认开启，关闭电量后仍保留时钟。

进度缩略图、视频视点和投屏等功能按现有视频源提供的数据或地址适配。
缺少数据或地址时，不显示对应入口。

## 平台接入

视频继续使用现有的 media_kit 播放会话。
Android 画中画、通知和后台服务控制同一个视频播放器。
视频后台服务不接管音声的媒体会话。

iOS 使用本地的 media_kit_video 2.0.1 补丁，为现有视频输出增加画中画。
画中画需要 iOS 15 或以上版本。
补丁采用软件纹理渲染和独立帧缓冲池，增加 CPU 与内存带宽开销。
补丁范围与真机检查要求见[插件说明](../../third_party/media_kit_video/KIKOFLU_PATCH.md)。
iOS 在画中画外播放无声音轨的视频时，系统不保证后台持续运行。
iOS 软件渲染不执行 GLSL 超分辨率，因此不显示该入口。

桌面画中画复用当前应用窗口。
退出后恢复窗口的位置、大小、最小尺寸、最大化、全屏和置顶状态。
桌面播放器支持置顶。
离开播放器时恢复原窗口的置顶状态。

Android 默认调节应用窗口亮度。
启用系统亮度需要用户授予“修改系统设置”权限。
系统亮度改动在退出播放器后保留。
窗口亮度、屏幕常亮请求和重力旋转在退出时清理。

定时关闭默认只暂停视频。
选择“退出应用”后，定时器会关闭整个应用。
超分辨率着色器与 MIT 许可证保存在 `assets/shaders/`。

## 实施顺序

1. 按固定源码核对控件、菜单、设置项与平台差异。
2. 复刻内嵌与全屏界面，接入现有视频源和本地视频播放。
3. 补齐通用播放能力，保留独立音量、手动续播和音轨选择。
4. 验证界面、播放行为与各平台的系统能力。

## 验收标准

- 在相同窗口尺寸、主题、语言和文字缩放下对照播放器界面。
  核对控件位置、尺寸、图标、文案、进度条及菜单。
- 横屏窗口为 20:9、视频画面为 16:9 时，视频控制层覆盖两侧黑边。
  控件按左右各自的系统安全区避让，进度条保留既定边距。
- 播放手势、快捷键和设置项遵循参照版本。
  播放设置跨重启保留，临时倍速、翻转和超分辨率按当前视频生效。
- 开启系统自动旋转时，分别竖拿和横拿手机退出全屏。
  视频详情页直接显示对应方向的布局。
- 关闭系统自动旋转时，退出全屏直接返回系统锁定方向。
  返回前不显示错误方向的详情页。
- 手动退出和自动退出都遵循方向恢复规则。
  切换全屏前后的播放状态和进度保持一致。
- 非全屏横屏时，播放器固定在左侧 40% 范围，全部信息在右侧 60% 范围滚动。
  旋转屏幕和退出全屏后保留当前视频及信息的滚动位置。
- 进入和退出全屏时，同一视频画面控件保持挂载。
  切换不经过黑色占位或全屏路由的淡入淡出。
- 在线视频和本地下载都能播放、跳转、切换全屏及恢复进度。
- 清晰度、字幕和音轨使用视频源实际提供的内容。
  缺少数据时不显示对应入口。
- 音声与视频同时播放时，双方的应用内音量互不影响。
- 已暂停的视频返回前台后保持暂停。
- 默认退后台或锁屏时暂停视频，并保存续播进度。
  开启后台播放或进入画中画后，视频继续播放。
- Android、iOS、Windows、macOS 和 Linux 分别验证播放与画中画。
  未验证的平台保留未验证状态，不以其他平台的结果代替。

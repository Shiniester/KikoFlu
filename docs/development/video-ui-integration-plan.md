# 视频页修正方案

本次修正覆盖 Android 视频播放和视频页的共享交互。
修正以音声、漫画的现有组件和行为为依据。

## 侧栏与搜索调整

2026-10-25 确认以下要求、保留入口和组合筛选方式。

### 已确认边界

- 视频侧栏只保留用户批准的入口。
  取消“在侧栏中显示所有能显示的内容”的旧规则。
- 从“内容”分组移除源站“素人”下的全部入口。
- 源站“无码影片”在侧栏只保留“无码流出”。
- 类型、女优、发行商等搜索条件放入视频搜索筛选。

### 批准清单

视频侧栏保留表中入口和“无码流出”。
源站新增入口不自动进入侧栏。
源站链接只更新已批准入口的目标地址。

### 组合搜索筛选

视频搜索支持关键词与类型、女优、发行商和系列条件组合。
条件选项从视频源目录读取，支持翻页选择。
选中的条件显示为可删除标签。
筛选覆盖完整查询范围，翻页保留条件。
更改条件后从第 1 页开始，取消旧请求的界面更新。

组合筛选读取关键词结果和各条件目录的完整分页。
结果按视频 ID 求交集，再使用本地分页。
源站直连返回浏览器验证页面，尚未确认原生组合查询参数。
目录较大时，组合筛选需要等待多次源站请求。
关闭搜索或更改条件后，停止旧查询的后续分页读取。
普通关键词查询继续使用源站分页。
收藏、观看历史和下载页继续搜索各自的完整集合。

### 验收结果

- 183 项视频、元数据搜索、共享页框架和底部播放条回归通过。
- 全项目静态检查未发现问题。
- 窄屏检查覆盖 320 像素宽、1.8 倍文字和软键盘。
- 本轮未实测真实源站筛选，未运行平台构建或设备验收。

## 已确认范围

1. 修复 Android 视频一直加载的问题。
   用户反馈几乎所有视频都无法播放。
   标题和简介已经出现，只有播放器区域一直转圈。
   Android 使用应用的“系统代理”模式。
   验收从正常应用入口打开视频详情并点击播放。
2. 视频目录只显示目录入口。
   翻页控件只放在页面底部，页码跳转复用音声的现有交互。
3. 视频集合提供大图标、小图标和列表 3 种布局。
   布局选择放在侧栏的“浏览选项”中。
4. 移除“升级 VIP”和“女优排行 OCT 2026”入口。
   月份变化后，同类排行入口也不显示。
   侧栏不显示语言切换项，视频源语言跟随应用选择的语言。
5. 移除视频页顶部重复的页面标签。
   视频页面通过侧栏切换。
6. 视频搜索复用音声、漫画的搜索交互。
   目录页搜索整个视频源。
   收藏、观看历史和下载页搜索各自的完整集合。
7. 修复保留侧栏入口的无响应和错误跳转。
   浏览功能在应用内完成。
   未接入的账号操作明确跳转到源站对应页面。
8. 视频页面切换时，音声播放条保持在底部。
   侧栏像音声一样在同一个视频页内切换目录。
   返回键不逐层退回以前选择的目录。
   从详情返回时，恢复刚才的目录和浏览位置。

## 修正前的代码与验证依据

- 视频搜索目前使用输入对话框，没有接入音声的搜索历史。
- 视频集合目前使用按宽度计算列数的固定网格。
- 源站导航解析接受同源导航链接。
  语言过滤只识别 `:href` 中的 `localizedUrl(...)`。
  其他形式的语言链接仍可能进入侧栏。
- 应用支持简体中文、繁体中文、英文和日文。
  视频源客户端尚未绑定应用语言。
  各语言的源站路径需按源站实际行为核对。
- [视频接入](../video-integration.md)记录了 Windows 真实播放验证。
  Android 仅记录构建通过，尚未实机验证。
  Windows 的结果不能证明 Android 的正常入口可播放。
- 真实源站测试没有传入 Android 所需的移动端 WebView。
  现有播放器组件测试使用替身播放器。
  原生播放测试直接读取本机文件，未覆盖 Android 在线媒体读取。
- 播放器打开请求完成前，加载状态不会结束。
  加载状态又优先于错误提示显示，可能遮住已记录的错误。
  这不能证明本次播放失败的根因。

## 复用方案

视频页沿用 `LibraryPageScaffold` 和现有侧栏分组。
视频卡片保留视频信息，布局选择和集合渲染使用共享组件。
视频布局偏好独立保存，参照音声和漫画的偏好范围。

侧栏入口按本方案的“侧栏与搜索调整”确定。
侧栏解析区分目录、分页、语言和会员链接。

`PaginationBar` 需要当前页码，以及总页数或可跳转范围。
现有视频分页模型只暴露上一页、下一页地址。
页码跳转范围以源站实际返回的信息为准。

音声和漫画分别提供搜索页。
复用搜索交互时，保留视频自己的搜索记录和查询能力。
音声专用的标签语法不直接传给视频源。
集合搜索覆盖完整集合，不只过滤当前页。

账号操作延续 [ADR 0005](../adr/0005-native-video-and-source-account.md)的功能边界。
未接入的账号操作显示源站入口，并说明操作位置。
找不到收藏、播放列表等入口时，不跳到源站首页代替对应页面。

目录切换与详情转场分别处理。
目录切换保留同一个视频页。
详情页继续沿用 [ADR 0001](../adr/0001-work-detail-bottom-dock-handoff.md)的底部播放条转场。

## 实施与验收顺序

1. 定位 Android 的实际播放故障。
   从播放器区域检查媒体读取、本机转发和播放器起播。
   核对本机媒体请求、浏览器响应及播放器打开请求的完成状态。
   请求失败时显示原因和重试入口，避免转圈遮住错误。
   在正常应用入口验证起播、进度前进和中段跳转。
2. 修正目录入口和语言选择。
   覆盖分页链接、会员入口、月份排行和语言切换链接。
   逐项检查保留入口的目标页面。
3. 接入共享布局、页面底部的分页控件和搜索交互。
   检查 3 种布局、页码跳转和已确认的搜索范围。
   搜索检查历史重选、单条删除、清空和返回后的结果恢复。
   覆盖当前页以外的收藏、观看历史和下载条目。
4. 接入共享底部播放条转场。
   检查前进、返回、连续切页和横竖屏。
   同时播放音声时，播放条不随目录页面移入或移出。

播放修复验收必须包含 Android 设备。
自动测试按定位结果覆盖故障，不以构建通过代替播放验证。

## 实施记录

源站语言由应用语言决定：简体中文使用 `/cn`，繁体中文不带语言前缀，
英文使用 `/en`，日文使用 `/ja`。
旧语言的目录和详情链接会转换为当前语言，保留目录路径和查询条件。

视频集合使用共享的 `LayoutType`、网格尺寸计算和虚拟列表组件。
布局偏好使用 `PersistentEnumPreference`，独立保存视频布局。
音声和漫画的完整搜索页没有可直接复用的公共输入组件；
视频页沿用输入、历史、清除和键盘提交交互，独立保存视频搜索记录。
收藏和观看历史搜索从第一页读取完整集合；下载搜索匹配全部本地任务。
演员收藏和播放列表目录列出的是入口，使用全站视频搜索。

源站把注册、重置密码和修改密码表单放在同一页面。
当前未查到各表单的独立地址，账号页明确提示打开源站后选择对应操作。
已登录时也显示“在源站修改密码”。
此入口不承诺直接打开对应弹窗。

目录切换在原有 `VideoScreen` 中加载，保留主页面底部的音声播放条。
播放列表子入口保留在侧栏，详情页继续使用现有播放条转场。

Android API 36 模拟器确认：媒体转发返回错误后，原生播放器会同时保留
错误和缓冲状态。播放器界面现已优先显示错误与重试入口。
原有验证流程只在原生网页读取失败时建立媒体转发。
验证现已同时接通浏览器媒体读取，避免网页正常时跳过这一步。
播放失败后可选择“验证访问”，验证成功后重新加载视频。
在全屏中选择此操作时，先退出全屏，再打开验证页面。
取消媒体读取按正常结束处理，避免退出播放器时抛出取消异常。

Android 浏览器已读取公开视频。
媒体通过本机转发交给原生播放器，并成功解码。
解码尺寸为 1280×720，播放进度超过 1 秒。
真实源站测试在加载网页时遇到连接错误，尚未进入媒体读取。
因此，真实源站在用户系统代理环境下的播放仍需复测。

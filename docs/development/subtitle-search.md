# 字幕搜索与播放行

播放器字幕页和作品详情页的字幕预览共用最近 1 个搜索关键词。

## 关键词记忆

- 打开搜索后，恢复最近的关键词。
- 关闭搜索、离开页面或切换作品后，关键词仍保留。
- 重启应用后，关键词仍保留。
- 主动清空输入后，清除记忆的关键词。

## 播放器搜索起点

输入或恢复关键词后，播放器先选择正在播放字幕之后的第一个匹配。当前字幕即使包含关键词，也不作为初次匹配。
如果后面没有匹配，播放器选择字幕中的第一个匹配。

上一个和下一个匹配按字幕顺序循环切换。同一条字幕中的多次匹配分别计数。

搜索只高亮和滚动字幕，不改变播放进度或播放状态。点按字幕仍按原有操作跳转播放进度。

作品详情页的字幕预览仍按全文顺序搜索。

## 播放行与时间

播放行位于播放器字幕页的固定纵向位置。一条浅色长横线贯穿字幕区域，左侧显示剪刀按钮，右侧显示播放行时间。

横线高 1 像素，不透明度为 15%。横线画在字幕文字后方。

播放行时间是播放行所指字幕在当前音轨上的起点时间。搜索结果移到播放行后，显示该结果所属字幕的时间。
手动滚动字幕时，显示播放行所指字幕的时间。

剪刀和时间优先放在原字幕两侧的留白中。留白不足时，字幕只为控件预留必要的空间。
剪刀图标缩小，点击区域保留。

## 按字幕创建切片

1. 搜索或滚动字幕，将起点字幕移到播放行。
2. 选择剪刀按钮，标记起点。
3. 搜索或滚动字幕，将终点字幕移到播放行。
4. 再次选择剪刀按钮，标记终点。

剪刀按钮使用播放行时间，不改变播放进度。终点必须晚于起点，切片不能重叠。
切片管理和播放规则见[音频切片](audio-slices.md)。

## 验证行为

- 播放至字幕中段后搜索，初次匹配位于正在播放字幕之后。
- 后方没有匹配时，初次匹配回到字幕中的第一个结果。
- 关闭并重开搜索、切换搜索入口或重启应用后，恢复最近关键词。
- 主动清空输入后，其他入口也不再恢复旧关键词。
- 搜索和标记切片均不改变播放进度，切片使用显示的播放行时间。
- 窄屏、宽屏和长字幕下，剪刀和时间不遮挡字幕，浅线连续贯穿字幕区域。

# 播放器音频文件筛选

播放器音频详情页按每个音频实际匹配到的字幕判断语言。没有匹配字幕的
音频显示为“无字幕”；字幕自身的简中、繁中标记优先于作品标题。字幕同时
带有简中和繁中标记时保留“未知”。只有已经匹配到字幕、但字幕未标明
语言时，作品标题中的中文语言标记才用于补充语言。

例如，作品标题为“简体中文版本”，目录包含 `01.wav`、`01.lrc` 和
`02.wav`，则 `01.wav` 属于简中字幕，`02.wav` 属于无字幕。手动选择
简中字幕时仅显示 `01.wav`。

## 计算与缓存

音频和字幕文件名复用现有 `SubtitleMatcher` 的预处理，原始字幕名与
移除语言标记后的字幕名各准备一次，模糊匹配规则保持一致。排序保留字幕
语言、格式、效果音、射精音、路径的优先级；已经有序的列表使用线性检查
跳过再次排序，比较时不创建临时排名列表。

音频列表由 `SliverList.builder` 按需构建。详情页仅在音频分类列表或筛选
条件变化时计算筛选结果；排队状态、主题等页面重建复用结果。作品文件树
变化时重置筛选条件。分类缓存的键包含目录边界，音频移入字幕所在目录
后会重新分类。

## 微基准

2026-10-05，在同一 Windows 主机使用 Flutter 3.44.7、Dart 3.12.2 的
Flutter 测试环境测量。每项预热 2 次，采样 5 次，取中位数；计时包含
相同的结果断言。分类场景为同目录的短音频名与带简中标记的字幕名；
筛选场景为 5000 个已分类音频。

| 场景 | 优化前（ms） | 优化后（ms） | 耗时减少 |
| --- | ---: | ---: | ---: |
| 40 个音频 + 40 个字幕分类 | 35.442 | 4.182 | 88.2% |
| 160 个音频 + 160 个字幕分类 | 436.142 | 15.869 | 96.4% |
| 5000 个音频，默认优选 | 5.703 | 0.877 | 84.6% |
| 5000 个音频，手动格式筛选 | 3.245 | 0.782 | 75.9% |
| 5000 个音频，关键词筛选 | 2.026 | 1.756 | 13.3% |

使用仓库锁定的 Flutter SDK 复测：

```powershell
flutter test --no-pub --reporter expanded tool/performance/player_audio_variant_benchmark.dart
```

## 限制与已知问题

同目录的音频与字幕仍逐对匹配，最坏情况随音频数和字幕数的乘积增长。
微基准使用合成文件名，不能代表长文件名、Android 真机帧耗时或网络加载
时间。

`player_code_performance_guard_test.dart` 中两项既有静态检查失败：封面
检查要求源码含有已经不存在的 `useOldImageOnUrlChange: true`；通知检查
要求应用仅有一处 `showSnackBar`，但现有漫画页也直接调用该方法。
这两个断言涉及的封面和通知代码未在本次修改。

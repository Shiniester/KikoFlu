# JP-ASMR 搜索

JP-ASMR 全局作品搜索通过 Eara 后端查询关键词和番号。结果按发行时间降序分页。

排序菜单提供“全部”和“全年龄”筛选。年龄分级独立于结果排序，也独立于作品主页的选择。搜索初始为“全部”，搜索历史保存并恢复筛选。切换筛选后，结果从第 1 页开始。

标签、声优和社团可作为关键词搜索。点击作品中的名称时，搜索使用作品所属的音声源。标签候选来自 Eara 搜索建议和已加载作品；声优候选来自搜索建议和已加载作品，社团候选来自已加载作品。候选不代表完整分类目录。

标签候选同时匹配原名和译名。选中标签后，应用使用原名请求 Eara。未匹配候选时，输入内容作为普通关键词提交。

Eara 不支持原有的分类组合与分类排除条件。旧搜索历史中的分类条件保留，但不能作为 Eara 的精确筛选执行。

关键词可直接使用空格、`|` 和 `-` 组合，例如 `耳かき -猫`。这些是关键词匹配，不等于分类精确筛选。

屏蔽列表支持手动输入标签、声优和社团名称。

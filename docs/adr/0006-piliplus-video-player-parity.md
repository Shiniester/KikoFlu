# ADR 0006: 视频播放器复刻 PiliPlus 并保留独立播放规则

视频播放器以 PiliPlus 2.1.6.2 的固定提交为参照。
复刻覆盖 Android、iOS、Windows、macOS 和 Linux。
各平台采用参照版本对应的界面、操作和设置，并补齐缺少的通用播放能力。
视频详情页保留现有结构。

为保留音声与视频同时播放，视频继续使用独立的应用内音量。
音轨选择等 KikoFlu 独有能力保留，入口采用 PiliPlus 菜单样式。
清晰度、字幕和投屏等功能适配现有视频源。
缺少源数据或地址时不显示入口，本次不新增 B 站接入。

后台播放默认关闭，普通退后台或锁屏时暂停视频并保存进度。
用户明确开启后台播放或进入画中画时，视频继续播放。
已暂停的视频返回前台后，仍需手动继续播放。

本决策替代 [ADR 0005](0005-native-video-and-source-account.md) 中的播放器界面与无条件后台暂停约定。
视频目录、账号和下载的资料归属继续遵循 ADR 0005。
固定提交、完整范围和验收标准见[视频播放器复刻约定](../development/video-player-piliplus-parity.md)。

# 按 ASMR 听感调整播放音效预设

日期：2026-11-14

## 背景

[ADR 0010](0010-common-audio-effects-backend.md) 和播放音效规格把场景参数固定为 Eara 基准。
按 10 个 Q=1 峰形滤波器叠加计算，原均衡器预设的最大提升达到 13～15 dB。
预设之间的 100 Hz～10 kHz 平均电平差约 8.9 dB，切换预设会同时改变音色和响度。
场景默认强度为 50% 时，三种场景的实际干声比例分别约为 0.68、0.29 和 0.20。
`闷声` 的原生参数是 through-wall，听感更接近隔墙声，不是被手或织物遮住的声音。

## 决定

- 保留 Eara 的滤波器结构、处理顺序和原生键，只调整参数值、文案和界面默认行为。
- 均衡器使用“明显版”曲线：最大叠加响应不超过 8 dB。
- 按 1/24 倍频程对数间隔、48 kHz 计算的 100 Hz～10 kHz 平均电平在 ±2.5 dB 内。
  44.1/96 kHz 的滤波器响应由 Python 原生检查覆盖；预设曲线的预算检查固定 48 kHz。
- `清亮`、`低音增强`、`清脆拍打`、`沉闷拍打`、`人声增强` 五条曲线按 ASMR 近讲人声、耳语和敲击重新取值。
- 场景重调为小浴室回声、被遮挡的闷声和经典窄带电话音。
- 场景默认强度改为 35%。
- 选中非“默认”均衡器预设时自动开启均衡器。
- 保留 `through_wall` 作为闷声场景的原生键，避免持久化、夹具和原生模板改名；界面标签仍为“闷声”。
- 中文文案把“拍打清脆/拍打沉闷”改为“清脆拍打/沉闷拍打”；英文和日文文案不变。

## 后果

- 播放音效不再逐值复现 Eara 的均衡器曲线和场景参数。ADR 0010 继续作为后端与 Eara 基准的历史记录。
- 需同步更新播放音效规格、Python 参数、生成的 Dart 模板、本地化文案和测试。
- 场景验证改为对照新的 KikoFlu 参数递推，不再要求匹配 Eara 固定输出。
- 原生 PCM 验收仍使用交付库并通过 CI 执行；本机没有 `libmpv`。
- 耳机试听使用 `C:\Users\Dong\Music\14_にゅるにゅる系耳奥舐め_両耳.wav`。试听完成前不得声称听感通过。
- 已保存的场景强度不会被改写；35% 只影响新安装、模块重置和全部重置。

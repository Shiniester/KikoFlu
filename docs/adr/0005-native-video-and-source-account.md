# ADR 0005: 视频使用 Flutter 页面并接入源站账号

视频功能采用 Flutter 页面，沿用 KikoFlu 的界面风格。
应用标签栏按音声、漫画、视频、设置排列。
横屏沿用侧栏导航。
视频页复用现有页头、抽屉和主题。
源站功能变化需要由 KikoFlu 跟进适配。

## 功能范围

[MissAV](https://missav.ai/) 是首个视频源。
首版包含源站账号，不包含会员能力。
首版覆盖 Android、iOS、Windows、macOS 和 Linux。
原生功能暂不可用时，提供“在源站打开”入口。
页面注明暂未接入的功能。

首版源站功能范围：

- 目录与搜索：首页、最新更新、新作、字幕专区、榜单、演员、分类、厂商及专题入口。
- 详情与播放：视频信息、相关推荐和原生播放控制。
- 账号：登录、退出、注册、密码管理、视频收藏、演员收藏、播放列表及观看历史。

## 播放规则

播放器位于视频详情页顶部，并提供全屏切换。
视频信息和相关推荐位于播放器下方。
播放控制包括播放/暂停、进度、倍速、独立音量和全屏。
清晰度和字幕选项以源站播放流提供的内容为准。
离开播放页、退到后台或锁屏时，暂停视频并保留进度。
返回播放页后，手动继续播放。
全屏切换保留当前播放状态和进度。

音声与视频允许同时播放。
音声和视频分别提供应用内音量控制。
调节一方的应用内音量不改变另一方的音量。
系统音量仍作用于设备总输出。

## 资料归属

| 资料 | 保存位置 | 未登录时的行为 |
| --- | --- | --- |
| 视频源收藏、演员收藏 | 视频源账号 | 提示登录，不保存本地收藏 |
| 播放列表 | 视频源账号 | 提示登录 |
| 观看历史列表 | 视频源账号 | 不显示 |
| 视频续播进度 | 本机 | 可用，重启后仍可恢复 |
| 视频下载 | 本机 | 源站允许访问时可下载；已完成的下载可离线播放 |

退出视频源账号后，保留本机下载和续播进度。

## 离线下载

首版提供视频离线下载。
离线下载供 KikoFlu 内播放。
下载任务提供进度、暂停、继续、失败重试和删除操作。
允许系统在后台或锁屏时暂停下载。
保留下载任务和已下载内容，返回或重启后可继续。
重启后，未完成任务恢复为暂停状态，可手动继续。

## 实施与验收

功能说明和检查结果见[视频接入](../video-integration.md)。

先核对源站协议和浏览器验证流程，再接入页面、播放及下载。
当前网络直接请求源站首页时遇到浏览器验证。
源站账号、视频播放和离线下载尚未完成真实访问验证。

验收覆盖以下行为：

- 目录、搜索和详情使用原生页面；暂未接入的功能可打开源站。
- 源站账号资料随账号切换，视频账号与音声、漫画账号独立。
- 音声与视频同时播放，分别调节音量；离页和后台暂停只影响视频。
- 续播进度跨重启恢复；下载可暂停、继续、重试和删除。
- 已完成的下载在断网时可播放。
- Android、iOS、Windows、macOS 和 Linux 分别验证播放与下载。

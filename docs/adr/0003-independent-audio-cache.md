# 播放音源与后台音频缓存分离

播放器只在加载时选择已下载文件、完整缓存或远程音频地址；远程音频的读取、
缓冲和进度跳转交给原生播放器。音频自动缓存使用独立的后台断点续传任务，
只有完整文件可用于后续播放，缓存任务不接管当前音源。

Android 在下一首预加载时间窗内，用同一原生播放器保留当前曲目和一首在线
候选音源。已下载文件和完整缓存继续使用现有的文件租约加载流程；没有完整
文件时才预备原远程地址，不改变音频格式。命中候选的切歌复用原生音源，应用仍负责
队列、循环和曲目状态提交；非 Android 继续通过后台缓存预加载下一首。
原生预备期间不同时为下一首下载完整文件，避免两条预加载任务争用带宽。

在线播放与后台缓存可能重复传输部分音频字节。接受这项流量成本，以移除
播放与缓存的字节拼接、写盘背压和预加载交接，保证缓存失败或取消不阻塞
播放控制。缓冲期间及用户下载占满容量时暂停后台缓存，保留现有完整缓存、
未完成前缀、下载文件和预加载设置。

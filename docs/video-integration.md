# 视频接入

## 使用

应用标签栏顺序为“音声 → 漫画 → 视频 → 设置”。视频页沿用现有资料库页的标题、搜索和抽屉。横屏使用现有侧栏。

视频页从 [MissAV](https://missav.ai/) 读取目录、搜索结果、分类、榜单、演员和厂商入口。详情页顶部内嵌播放器，下方显示视频信息、演员和相关推荐。

播放器提供播放、暂停、进度、倍速、音量和全屏。可用画质和字幕以视频流为准。打开详情后手动播放；离页、页面被覆盖、后台或锁屏时暂停，返回后手动继续。全屏共用同一个播放器。

音声与视频使用独立播放器，应用内音量互不影响。系统音量仍控制设备总输出。

## 播放手势与视频卡片

播放器参考 [PiliPlus](https://github.com/bggRGjQaUbCoE/PiliPlus) 的控制交互。

- 播放时，停止操作 3 秒后隐藏控制。单击画面可显示或隐藏控制。
  暂停、加载和缓冲时也可隐藏控制。
- 主控制在画面内显示为单行。音量、倍速、清晰度、音轨和字幕位于设置弹层。
  加载指示器不拦截画面手势，播放失败时保留恢复操作。
- 双击画面可播放或暂停。
- 横向拖动画面可预览目标时间。松手后跳转，取消手势时保留原进度。
  横拖以当前进度为起点，滑过整个画面最多调整 120 秒。
  拖动进度条也在松手后跳转。
- 播放时长按画面可临时切换到 2 倍速。
  松手、取消手势、离页或退到后台后恢复先前倍速。
- 聚焦播放器后，空格播放或暂停，左右方向键后退或前进 5 秒。
  **F** 切换全屏，**Esc** 退出全屏。

视频卡片沿用音声页的 4:3 封面和 80×60 像素列表封面。
大网格和小网格使用可变高度，按内容显示女优名和标签。
女优名和标签可打开对应的源站目录。
女优名和标签沿用音声默认卡片的字号、行距和主题颜色。
卡片最多显示 2 个女优名，其余显示为数量入口。
视频标签全部显示，不限制数量。
列表将女优名和标签排在封面右侧。
相关推荐和下载封面共用同一封面组件。

时长位于标题下方，沿用音声卡片的蓝色时长文字和时钟图标。
封面左下角显示字幕和无码图标，右下角显示发布日期。
打开“设置 → 视频设置 → 界面设置 → 作品卡片显示设置”，可选择显示的信息。
默认开启时长、发布日期、字幕标签和无码标签。
发行商、厂牌、系列和导演默认关闭。
女优和视频标签始终显示，不提供开关。
视频卡片设置独立保存，不影响音声设置。

视频列表通过 MissAV 的 Recombee 接口批量补充元数据，缺失项留空。
接口按当前视频 ID 筛选，一次返回多条属性，保留原列表顺序。
女优名取 `actresses`，标签取 `genres`，不把 `actors` 当作女优名。
同名条目保留源站已有的目录链接。
发布日期、时长、字幕和无码标记也由该批量响应补充。
发行商取 `markers`，厂牌取 `labels`，系列取 `series`，导演取 `directors`。
当前视频和相关推荐共用一次批量查询。
批量请求使用独立客户端，不携带源站账号 Cookie。
接口失败时保留原卡片。浏览列表不会逐个请求视频详情。
下载保存已有元数据，离线详情可显示这些信息。
旧下载中没有的元数据继续留空。
旧下载中混在标签里的发行商、厂牌、系列和导演，按对应开关显示。

## 浏览与分页

侧栏“内容”只保留主页、最近更新、新作上市、中文字幕、本周热门和无码流出。
侧栏保留 MissAV 账号、视频收藏、演员收藏、播放列表、观看历史、视频下载和布局。
源站新增入口不自动进入侧栏。
演员收藏和播放列表的子项显示在对应页面正文。

视频搜索提供类型、女优、发行商和系列条件，可与关键词组合。
条件选项从源站目录读取，支持翻页选择。
已选条件显示为可删除标签，清空输入时同时清空条件。
组合筛选读取完整查询结果和各条件目录，按视频 ID 求交集后分页。
目录较大时，组合筛选会比普通关键词查询慢。
更改条件后从第 1 页开始，旧查询停止读取后续分页。
收藏、观看历史和下载页继续搜索各自的完整集合。

点击“布局”，按大网格、小网格、列表的顺序循环切换。
视频布局单独保存，重启后恢复。

分页条位于列表末尾，提供上一页、页码跳转和下一页。
源站提供分页时，按源站页面翻页，跳转范围以源站提供的页码为准。
首页等未提供源站分页的页面，只对已加载的视频分页。
收藏和历史的范围搜索、本地下载及下载搜索也提供分页。
本地分页沿用应用的每页数量设置。
本地列表只有一页时，显示列表结束提示。

## 账号与资料

| 功能 | 保存位置与行为 |
| --- | --- |
| 登录 | 支持源站邮箱和密码，也可在验证窗口登录。会话 Cookie 和对应 User-Agent 写入系统安全存储，不保存密码 |
| 视频收藏、演员收藏 | 写入源站；未登录时提示登录，没有本地收藏副本 |
| 播放列表内容 | 读取源站列表，支持添加和移除视频 |
| 观看历史 | 读取源站列表，支持确认后清空；未登录时不显示列表 |
| 续播进度、视频音量 | 保存在本机，重启后恢复 |
| 退出 | 清除本机源站会话，保留本机下载和续播进度 |

注册、找回密码、修改密码，以及播放列表的新建、改名和删除，提供源站入口。这些操作尚未完成原生协议验证。会员功能不在首版范围内。

源站账号与音声、漫画账号独立。Cookie 只发送到 `https://missav.ai`，不发送给媒体 CDN。浏览器媒体请求不携带认证信息。账号切换使旧请求失效；源站验证页不会被当作登录成功。

Android 排除安全存储文件的云备份和设备迁移，避免恢复无法在新设备解密的会话。macOS 使用系统传统 Keychain，避免为未配置 provisioning profile 的分发增加 Keychain Sharing 要求。Linux 构建需要 `libsecret-1-dev`，运行需要 `libsecret-1-0` 和可用的桌面密钥环。

## 浏览器验证

重启应用后，首次在线访问会恢复已保存的源站浏览器会话。恢复后自动检查访问。
源站返回验证页时，视频页、详情页和账号页显示“验证访问”。在应用打开的源站窗口完成验证或登录后，点击“检查访问”。Windows 使用独立的 WebView2 配置目录保存源站浏览器会话。

当前网络中，导入浏览器 Cookie 后的原生请求仍返回 HTTP 403。网页读取改用已验证浏览器的普通页面导航。账号 API 使用同一浏览器内的请求。视频页和播放器仍使用 Flutter 界面。浏览器中的页面导航与 API 请求按顺序执行，避免导航打断账号操作。

Windows 和 Android 的验证浏览器使用应用代理设置。Android 与 Japanese ASMR 验证共用代理协调器，关闭一个验证窗口不会移除另一个会话的代理。iOS、macOS 和 Linux 的验证浏览器目前需要系统代理模式。Linux 构建还需要 `libwebkit2gtk-4.1-dev` 和 `libsoup-3.0-dev`。

媒体 CDN 的原生请求同样返回 HTTP 403。媒体改由独立的源站浏览器读取，再通过本机转发交给播放器和下载器。浏览器按片段流式传输数据；HLS 清单中的地址改写为本机地址。媒体浏览器与网页浏览器分开，浏览目录不会打断播放或下载。

退出视频源账号会清除源站浏览器会话。取消验证或切换账号后，旧连接不能导入迟到的会话，也不能发送旧账号操作。关闭会话时，同时取消媒体读取并关闭本机转发。

## 离线下载

下载页提供队列、进度、暂停、继续、重试和删除。未完成任务在重启后恢复为暂停状态，手动继续时重新获取源站流地址。任务文件不保存流地址或认证请求头。

媒体浏览器未暴露 `Content-Range` 时，继续下载会重新读取当前片段。已完成片段保留，不会重新下载。

支持 MP4 和 HLS VOD。HLS 下载会保存清单、媒体片段、初始化片段和 AES-128 identity 密钥，并改写为本机相对路径。已完成的视频直接读取本机文件，不依赖源站访问或账号安全存储。

首版不下载实时或低延迟 HLS、字节范围清单、独立音轨和其他 DRM 格式。下载失败会保留任务供重试。系统可在后台暂停任务；首版不保证进程被结束后持续下载，也不提供通用文件导出。

## 实施交接

- `task_brief`：新增 MissAV 原生视频页、源站账号、独立播放和可恢复下载，保留现有页面结构。
- `dispatch.read_only`：入口定位顾问核对导航、音频会话和下载复用边界；独立评审者核对会话、下载和播放器生命周期。
- `dispatch.write_stages`：先确定模型与公有接口，再由三个 Flutter writer 分别修改源站、离线和界面文件。主执行者负责依赖、主导航、本地化、平台配置、组合验证和文档。共享 Flutter 命令串行执行。
- 媒体接入阶段：沿用 `RemoteAssetTransport` 契约，由两个 Flutter writer 分别编写浏览器媒体传输与本机转发。文件归属独立。主执行者负责会话集成和真实验证，独立评审者检查取消、续传及重连。
- `dispatch.skipped`：没有另派构建、依赖、测试和文档 writer；主执行者与模块 writer 已覆盖这些任务，避免重复归属。

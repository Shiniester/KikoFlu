# 搜索条件区域展开

范围：`lib/src/screens/search_screen.dart`。

标题、条件行和间距形成独立区域。以顶部为锚点，200ms easeOutCubic 控制高度和透明度。仅空／非空状态变化调用 animateTo；控制器保留当前值，所以快速添加／删除可正反接续。非空列表内部变化不重播动画。

条件区保持结构稳定，下方搜索表单不因显隐改变身份；搜索逻辑、顺序、输入焦点沿用原行为。隐藏时禁用交互与语义。减少动态效果直接设控制器端点，横向定位使用 jumpTo。

自动覆盖：`test/browse_motion_test.dart` 检查首次展开、中途第二个条件不重启、删空反转和表单 Element 身份。
